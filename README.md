# Hamparan D — Frontend (GitHub Pages)

Aplikasi pencatatan panen & kas Kelompok Tani "Citra Abadi" Hamparan D.
Frontend statis (HTML/CSS/JS) yang berbicara dengan backend Google Apps Script lewat `fetch()`.

- `index.html` — kerangka aplikasi
- `css/style.css` — tampilan
- `js/config.js` — **isi `GAS_URL` di sini** (URL Web App berakhiran `/exec`)
- `js/app.js` — logika aplikasi

Backend (`Kode.gs`) TIDAK ada di repository ini; ia ada di proyek Google Apps Script.
Lihat `PANDUAN-INSTALASI.md`.
